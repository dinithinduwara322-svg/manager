match /templateReleases/{release} {
  function isUploader() {
    return request.auth != null && request.auth.uid == 'YOUR_MANAGER_UID';
  }
  allow get: if true;
  allow create, delete: if isUploader();
  match /parts/{part} {
    allow get: if exists(/databases/$(database)/documents/templateReleases/$(release));
    allow create, delete: if isUploader();
  }
}

Template ZIP limit 50 MB compressed, 600 files, 115 MiB unpacked. Use built static HTML, CSS, browser JS and relative image/font/media links. Server-side code and build steps must run separately. Scripts that import modules or request additional local files at runtime may need a hosted template URL. Internet access and available Firestore storage, read/write and bandwidth quota are required. Each upload creates a new version. Large media-heavy templates consume quota faster. Existing Cloudflare R2 links still require their original worker and bucket.
